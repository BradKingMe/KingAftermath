# Interface direction

Mode: Operate. A quiet evidence workspace for Windows users. Native HTML controls and custom CSS; no claim of implementing an official Microsoft design system.

Palette: cool white and gray surfaces, deep blue-green text, one muted green action accent. Restrained green/amber/rust indicators communicate change types with matching text and symbols. No external images, fonts, animation libraries or icon dependencies.

Typography: Windows Segoe UI with Arial/system fallback. Consolas for paths, commands and identities. Sentence-case headings, compact labels and comfortably readable detail text. No decorative hero illustration; the capture timeline and field diff are the visual focus.

Structure: top product bar; left capture timeline; right comparison modes, summary and coverage disclosure; filter bar; selected-record list and evidence pane. At narrower sizes the detail pane moves below the list; mobile puts capture controls above the comparison. Evidence remains visible rather than hidden in a hover-only interaction.

Accessibility: semantic landmarks/headings, visible focus rings, skip link, explicit input labels, native dialog with close button/Escape support, press-state filters, text alongside status colors, reduced-motion support, wrapping paths and paginated long lists. Captures load into tab memory with clear persistence warnings.

Corner scale: 7px containers/buttons, 4px subordinate controls, circular status dots. Hierarchy comes from spacing, rules and selected-row fill, without decorative shadows or gradients.

0.2: application investigation adds a registration hub and four category lanes with selectable evidence nodes. Match reasons, target health and coverage remain inspectable. Mobile lanes stack; a native selector retains every match beyond the map display cap. Notes and decisions use labeled forms/disclosures and remain separate from observations. The native capture desk uses Windows Forms, fixed profiles and asynchronous capture status.
