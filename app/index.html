FROM YOUR WINDOWS PC

Capture once, or follow an install.

Windows capture desk: double-click Capture.cmd in this project folder. Create a named investigation, optionally add application folders, then use the three capture buttons. You can also capture once and use Investigate an app. The launcher keeps the folder scope fixed and shows where each capture was saved.

Use the same Windows account, collector version and privilege level for every capture. Close unrelated installers and updaters to reduce background changes.

  1. Before you install

    Download the collector into your project folder. In a 64-bit PowerShell terminal, run:

    powershell -NoProfile -File .\collectors\Capture-KingAftermath.ps1 -Label "Before install" -OutFile .\captures\before.json
  2. After you install

    Install your chosen app normally, then capture again:

    powershell -NoProfile -File .\collectors\Capture-KingAftermath.ps1 -Label "After install" -OutFile .\captures\installed.json
  3. After you uninstall

    Uninstall through Windows Settings, wait for it to finish, then capture:

    powershell -NoProfile -File .\collectors\Capture-KingAftermath.ps1 -Label "After uninstall" -OutFile .\captures\uninstalled.json

A standalone download may land in Downloads. Move it into a collectors folder before using these commands, or change the script path. Follow your organization’s script policy. Administrative access can improve coverage; it is not requested automatically.

What gets captured?

Application uninstall registry records, Run/RunOnce entries, startup folder file hashes, service configuration and selected task configuration. No file contents from application folders, browser profiles, passwords or browsing history are collected. Command arguments and local paths can still be sensitive.

This is a bounded inventory, not a complete forensic record. No browser extensions, drivers, arbitrary registry changes, package-store inventory or other users’ profiles are covered in v0.1.
