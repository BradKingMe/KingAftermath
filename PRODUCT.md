# KingAftermath

Audience: Windows users, developers and IT staff who want to understand configuration changes around an install/uninstall.

Primary task: load before/installed/optional uninstalled captures, understand observed differences, inspect source evidence and export a report.

Product boundary: manually invoked read-only collection, no cleanup, no attribution certainty, no cloud upload, no AI-generated judgment. Incomplete evidence stays visible. Local-first and dependency-free for a low-friction GitHub project.

First release: four Windows configuration categories; stable machine/user/scope checks; source-specific coverage; install/uninstall/residual views; raw evidence; filters; CLI and portable HTML reports; fictional demo.

Next project: KingReceipt remains a separate product and repository, to be built after this one.

0.2 expansion: single-capture investigation, explainable footprint map, native capture desk, target observations, optional bounded file manifests, portable review packages and enriched reports. Collector remains read-only; relationship strengths express heuristic evidence, never ownership or security confidence.
